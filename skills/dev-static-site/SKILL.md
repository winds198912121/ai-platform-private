# 静的 HTML サイト開発規約

## Overview
実行側は Node 標準ライブラリと node --test だけです。テンプレートを純粋関数、内容をデータ、ページを文字列として実行・検証します。CSS・フォント・画像・Astro / Hugo / 11ty / Vite などは設計・デプロイ文書へ記載します。

## When to Use
- ビルド不要の静的 HTML のデータ、テンプレート、経路、リンク、ページ分割、SEO、i18n の開発・レビューに使用します。
- 対象外：React + Vite（dev-react-vite）、プラットフォーム内でブラウザー操作を実行する要件。

## Core Process
- npm install、バンドラー、CDN、外部資源の import を実行モジュールへ導入しません。
- content のデータ→(data) => html のテンプレート→経路とページの組み立て→全経路の構築と分離します。文言・リンク・項目をテンプレートへ直書きしません。
- テンプレートは純粋にし、グローバル状態・Date.now()・Math.random() を参照せず、時刻と乱数を注入します。
- データ・入力を HTML へ入れる前に & < > のほか引用符とアポストロフィーも esc() でエスケープし、属性値を引用符で囲みます。未処理の値を script、on*=、javascript: へ入れません。URL は http / https / mailto / 相対パスの許可リストで検証します。
- 各ページの title、description、canonical、唯一の h1、現在ページの active を具体的に検証し、div を含むことだけで成功にしません。
- routes() が返す {path, title, template} を唯一の経路定義とし、全リンクをそこから生成します。各 href が経路表または許可された外部リンクにあることを検証します。
- ページ指定 {page, perPage} を引数で受け、{items, total, hasNext} を返します。数値・日付の並べ替えには明示的な比較関数を使います。
- html lang、header/nav/main/footer、連続した見出し階層、画像 alt、フォーム label を成果物として検証します。
- CSS は assets/ へ配置し、テンプレートに大量の inline style を入れません。圧縮・結合・CDN・公開スクリプトはデプロイ工程で扱います。
- 実行済みなのはデータ・レンダリング・経路です。カルーセルやフォーム送信などのブラウザー挙動は、結合テスト一覧にプラットフォーム内では未検証と明記します。
- アイコンは inline SVG または文字、フォントはシステムフォントを使い、外部資源が必要な場合はデプロイ文書に記載します。

## Common Rationalizations
| よくある説明 | 確認すべき事実 |
|---|---|
| 静的サイトなのでテスト不要 | 実際に生成した title・リンク・構造・アクセシビリティを検証します。 |
| テンプレート内の直書きが簡単 | 内容をデータへ分離し、同一入力で同じページを生成します。 |
| 静的データはエスケープ不要 | すべてのデータをエスケープし、URL のプロトコルを検証します。 |
| CDN なら依存なしと同じ | 実行モジュールは外部資源を参照できません。 |
| 文字列テストが通ればブラウザーも検証済み | ブラウザー固有の挙動は別の未検証項目として記録します。 |

## Red Flags
- テンプレート内の固定内容、グローバル状態、未エスケープ値、javascript: URL があります。
- 経路一覧が複数あり、リンク切れ、既定の文字列順ソート、SEO・label・alt の欠落があります。
- 外部 import / CDN、過大な inline style、未実行のブラウザーテストを成功扱いしています。
