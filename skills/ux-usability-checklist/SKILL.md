# 画面ユーザビリティ確認

## Overview
状態の可視性、利用者の制御、操作の一貫性、予防的な検証、文脈、修正可能なエラー、高頻度操作の効率を確認します。

## When to Use
- UX フェーズの引き渡し前の自己確認・レビュー。
- 対象外：スタイル選定とブランド設計。

## Core Process
- 時間のかかる操作は進捗またはスケルトンを示します。1 秒超で反応を返し、10 秒超では見通しを説明します。あらゆる操作に結果を示します。
- 取り消し・戻る操作、削除の再確認、更新・切断でも入力を失わない下書き保護を用意します。
- 同じ操作には同じ文言と位置を使い、保存と送信を混同しません。危険操作は専用の外観にし、主要ボタンに隣接させません。
- 適切な既定値と入力時の形式制約で誤りを予防し、読み取り専用項目は明示的に無効化して送信後に初めて失敗させません。
- 選択項目はコードだけでなく読めるラベルを示し、対象の人・プロジェクトなど重要な文脈を常に表示します。
- エラーはどこが誤りか、理由、直し方を説明し、具体的なフィールドへ関連付けます。
- 高頻度経路は 3 操作以内を目指し、自然な Tab 順と Enter 送信、一括選択、部分失敗の結果を提供します。

## Common Rationalizations
| よくある説明 | 確認すべき事実 |
|---|---|
| 処理中は点を点滅させれば十分 | 経過の見通しと結果の反応が必要です。 |
| 入力は送信時だけ確認する | 入力中の制約と明確な読み取り専用表示で誤りを防ぎます。 |
| エラーコードだけ返せばよい | 場所・理由・修正方法を示します。 |

## Red Flags
- 時間のかかる操作に進捗・反応・結果がありません。
- 下書きが失われ、取り消し・戻る操作がありません。
- 用語と位置が一貫せず、危険操作が主要操作に紛れています。
- 文脈・読めるラベル・エラーの修正方法・部分失敗の説明がありません。
