# WBS 見積もりと依存関係

## Overview
三点見積もり、クリティカルパス、独立したバッファ、外部依存、判定可能なマイルストーンを作成します。

## When to Use
- Task の工数、並行可能性、バッファ、外部依存、マイルストーン条件を計画するとき。
- 対象外：粒度と受入基準の分解（wbs-module-granularity）。

## Core Process
- 楽観・最頻・悲観の三点値と、参照モジュールや複雑さの根拠を示します。単一値だけの見積もりは禁止します。
- 全体工期を決める直列 Task のクリティカルパスを明示し、非クリティカル経路の並行度と挿入条件を示します。
- 総バッファをクリティカルパスの 15–25% として独立表示し、消費ルールを定めます。各 Task の中へ隠しません。
- 外部依存の相手、必要な前提成果、最終確認期限、不成立時の一時的な縮退方式を別表にします。
- 日程は相対的な週次と判定条件で記載します。例：第 1 週末にすべての要件が承認済み。根拠のない日付だけにしません。
- 各マイルストーンに、承認済み成果物と成功すべきテストを含む開始条件・終了条件を定義します。

## Common Rationalizations
| よくある説明 | 確認すべき事実 |
|---|---|
| 見積もりは 1 つの数値で十分 | 三点値と根拠を提示します。 |
| 余裕は各 Task に入れる | バッファを分離し、消費規則を明示します。 |
| 日付があればマイルストーンになる | 成果物の承認とテストの開始・終了条件が必要です。 |

## Red Flags
- 根拠のない単一見積もり、未定義の依存・並行度があります。
- バッファが隠れ、外部依存の期限・代替策がありません。
- マイルストーンに開始・終了判定がありません。
