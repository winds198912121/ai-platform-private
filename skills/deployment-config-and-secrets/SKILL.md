# 設定と秘密情報の管理

## Overview
環境非依存の既定値、環境別設定、秘密情報を分離し、起動時検証、更新、監査を定義します。

## When to Use
- デプロイ時の設定分類、設定の追加・変更、秘密情報の更新、本番設定変更に使用します。
- 対象外：一時的なローカルデバッグ設定、デプロイ前の設計検討（security-baseline）。

## Core Process
- 環境非依存の既定値はコード、環境別値は環境変数・設定管理、秘密情報は秘密管理サービスに分けます。
- キー、型、既定値、必須可否、同時変更が必要なインスタンス、再起動の要否を登録します。
- 必須設定の不足や形式誤りは起動時に明示的な理由を出して起動失敗にし、空値のまま稼働させません。
- 秘密情報の更新周期、責任者、新旧併存→切替→旧値無効化の手順、検証と更新中の戻し方を定めます。
- 設定変更は担当・変更キー・環境・検証方法を変更管理へ残し、機微値をマスキングします。
- 環境別設定と秘密の実値をリポジトリや例へ含めません。.example には取得方法と例示値だけを記載します。

## Common Rationalizations
| よくある説明 | 確認すべき事実 |
|---|---|
| 空の設定でも起動させて後で直す | 起動時に失敗し、理由を明示します。 |
| 秘密情報は値を置き換えるだけ | 新旧併存、切替、無効化、検証と戻し方が必要です。 |
| サンプルなら実際の秘密を記載してよい | .example には例示値と取得方法だけを載せます。 |

## Red Flags
- 設定の分類と出所、型・既定値・必須・影響範囲が不明です。
- 起動時の検証、更新中の検証と戻し方、責任者がありません。
- 変更記録やサンプルに実際の秘密が含まれます。
