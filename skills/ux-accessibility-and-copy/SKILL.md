# アクセシビリティと画面文言

## Overview
WCAG AA、キーボード、フォームの関連付け、意味構造、明確な操作文言、切り詰めと翻訳を画面仕様に含めます。

## When to Use
- UX フェーズで画面のアクセシビリティと文言を設計・レビューするとき。
- 対象外：バックエンド API、データモデル、画面と関係のない説明図。

## Core Process
- WCAG AA を基準に本文 4.5:1 以上、大文字 3:1 以上のコントラストを確保します。エラーは色だけでなくアイコン・文字でも示します。
- 全操作へ Tab で到達でき、focus スタイルが見えるようにします。ダイアログ内にフォーカスを制限し、Esc で閉じられるようにします。
- 全入力に label を付け、placeholder で代替しません。エラーは aria-describedby で関連付け、必須項目は文字でも示します。
- 見出しレベルを飛ばさず、操作は button を使い、画像に alt、装飾画像に空 alt を設定します。
- 操作文言は保存・送信・削除など動詞を使い、意味の不明な OK / Yes / No だけにしません。用語は設計書と統一します。
- 一覧の最大長と省略記号・title による全文確認を定義します。日本語・English 混在の幅を文字数だけで推測しません。
- 文言は「{n} 件を選択」のようなプレースホルダーで翻訳可能にし、文字列の連結や語順だけに意味を依存させません。

## Common Rationalizations
| よくある説明 | 確認すべき事実 |
|---|---|
| 色でエラーが分かる | アイコンと説明文を併記します。 |
| placeholder があれば label は不要 | 常に関連付けられた label が必要です。 |
| 文字を順に連結すれば翻訳できる | 言語ごとの語順に対応できるプレースホルダーを使います。 |

## Red Flags
- 低いコントラスト、色だけの通知、不可視フォーカスがあります。
- クリック可能な div、label の欠落、関連しないエラー、見出しの飛びがあります。
- 曖昧な操作名、未定義の省略、文字列連結があります。
