## 7. 環境依存（11件以上）

### test/exec.test.mjs（6件、**すべて JDK 必須**）
- 真实跑 Java
- 缺 JDK 时明确失败
- Java 模块级执行只编本模块
- CDS 结构性校验
- 测试进程挂住不会挂住流水线
- 工作区里没有可执行产物时

Mac に JDK が入っていない or `javac` のパスがズレていると一斉に red になる。PROGRESS.md の「实测」は別マシン or `tools/setup` 後の状態での数字。本機では # P0-2（Docker smoke）と同時に **colima + JDK 17 を入れる**のが最短経路。

### test/agent.test.mjs（5件以上、**モデルプロバイダ必須**）
- 阶段模型真的发到模型服务
- WBS 与模块开发各自用自己阶段定义的模型
- modelFor：定义优先
- 输出被截断 → 重试
- 技能库真的随提示词发出去了

これらも実プロバイダ必須。`AI_PLATFORM_PROVIDER=sim` でも一部は fake server が立つが、本物の e2e には本物の provider が必要。

**作業コスト**：環境セットアップで 0 個解消するが、テストそのものは触らない。
